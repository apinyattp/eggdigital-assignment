คู่มือทดลอง Meeting Scheduler

เปิด Wireframe · เปิด UI design

ต้นแบบแบบคลิกได้ ใช้ข้อมูลสมมติ ไม่มีบัญชีหรือบริการจริง ไม่ใช่แอปที่พร้อมใช้งานจริง

  1. หน้า Login มีบัญชีเดโมให้ กด Login เพื่อดู Dashboard หรือเลือก Mock Google identity เพื่อทดลอง Member/Guest โดยไม่มี OAuth จริง
  2. เปลี่ยน Staff demo profile เพื่อทดลองการเห็นนัดของแต่ละบัญชี แถบ List state มี loading/empty/error และการลองใหม่
  3. Dashboard แบ่ง Upcoming/Current, Cancelled/Rejected และ Past; กลุ่มแรก10รายการต่อหน้า อีกสองกลุ่มแสดงล่าสุดกลุ่มละ5รายการ ลอง ข้อมูลเดโมหลายรายการ และเปลี่ยน Preview clock เพื่อดูการจัดกลุ่ม
  4. Add New Meeting ใช้วันเริ่มตั้งแต่วันนี้ วันเวลาจบต้องอยู่ในอนาคตและหลังวันเวลาเริ่ม รองรับข้ามวัน Edit ล็อกวันและเวลาเดิม
  5. เปิดรายละเอียดนัดเพื่อทดลอง Notes, Feedback และ dialog ใช้ Next mock request ทดลอง save/read failure ข้อมูลที่บันทึกจำลองอาจคงอยู่ใน browser storage; ล้าง site data เพื่อเริ่มใหม่
  6. Feedback100รายการ ใช้ข้อมูลสมมติแยกสำหรับดูการอ่านย้อนหลัง

รูปแบบหน้าจอ

Wireframe ใช้โครงร่าง ส่วน UI design ใช้สี ตัวอักษร รูป และรูปแบบ responsive เดียวกับต้นแบบที่จัดส่ง ไฟล์สีอยู่ใน design-tokens.css และ CSS ใน HTML
